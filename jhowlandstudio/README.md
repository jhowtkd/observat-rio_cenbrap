## 🚀 Quick Start

Os agentes estão disponíveis automaticamente no Claude Code. Descreva sua tarefa e o agente apropriado será acionado.

### Exemplos de Uso

```
"Otimize a performance desta página"              → ⚡ bolt
"Revise este código por segurança"                → 🛡️ sentinel
"Crie um MVP de app de delivery"                  → 🚀 rapid-prototyper
"Melhore a acessibilidade deste componente"       → ♿ a11y-specialist
"Analise o schema do banco de dados"              → 🗄️ database-engineer
"Faça code review deste PR"                       → 👀 code-reviewer
"Adicione testes para esta feature"               → 🧪 test-writer-fixer
"Crie conteúdo para Instagram"                    → 📷 instagram-curator
```
